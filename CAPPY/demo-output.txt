Demo mode: simulated
Simulated mode: no live cloud contracts or provider credentials are required.
Transport note: exchanges are illustrative in-memory messages; no HTTPS request is sent.

Demo journey:
1. Read health data from an EU healthcare structure using FHIR.
2. Check jurisdiction, consent, and routing rules before transmission.
3. Normalize data so a multi-cloud application can work with it.
4. Write normalized data to an EU healthcare structure using FHIR.
5. Prepare data for an FSE exchange from an authorized application or institution.
6. Prepare a temporary cloud transfer authorized by the citizen.
7. Illustrate smartwatch monitoring data read from a cloud platform and prepared for FSE.
8. Illustrate temporary cloud sharing for in-flight assistance or care in another country.
9. Illustrate routing an authorized clinical summary to an OpenHospital-compatible endpoint.
